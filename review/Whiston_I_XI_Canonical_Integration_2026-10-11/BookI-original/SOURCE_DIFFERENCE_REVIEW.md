## Greek control at I.272

The project Greek has the 272 label before τῆς τριχὸς βάθος, inside Isaac's preceding quotation. The printed Niese witness (1887, printed p.65, PDF155; image evidence/Niese-printed-p65-155.png) places the marginal number on a line containing the end of that quotation and the new καὶ μηδὲν ὑπολαβὼν clause. Lexundria starts English 272 with So suspecting no deceit, which corresponds to the new clause. The pilot follows that position. Marginal line placement alone does not imply a section starts with the line's first word. Greek remains unchanged; this discrepancy needs separate project adjudication before a complete cross-language certificate can be issued. I.273 in the project begins ταῦτ᾽ οὖν καὶ βεβαίωσον and agrees with Lexundria and print.
