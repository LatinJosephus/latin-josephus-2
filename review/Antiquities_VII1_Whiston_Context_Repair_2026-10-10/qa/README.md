# Reproducible local checks

Dependencies: Ruby/Jekyll as in the baseline native builder, Node, Playwright and Chrome. Set PLAYWRIGHT_MODULE to the installed Playwright module path, CHROME_EXECUTABLE if necessary, REPAIR_RUNTIME to a separate writable evidence directory, and REPAIR_ROOT to this isolated worktree. Build baseline from the verified frozen commit into baseline-site and the repair into candidate-final-site using build.rb and local.yml. Disk caches and incremental builds are disabled. The optional responsive-image plugin is excluded exactly as in the established native builder; no image source changes are involved.

Run `node VII1-context-regression.test.cjs <built-site> <label>` for the permanent positive regression. The frozen baseline must fail its positive narrative assertion; the final candidate must pass. Run `node all-niese.cjs baseline` and `node all-niese.cjs candidate-final` for all actual dropdown identities. These servers deliver the unmodified built renderer. Compare each pane DOM/text, IDs, notice arrays, menus and duplicate-ID counts, allowing only VII.1 English context recovery.

Run context-guards.cjs, targeted-ui.cjs and containing-real.cjs for focused checks. The structural suite reader-structure-crosswork.cjs requires BUILD_CONTEXT.json with baseline_site/site and AUTHORIZED_ADDITIONS.json containing []. Its qa-common18.cjs exports existing reader functions and navigation state solely to enumerate every projection; it does not replace selection functions or mutate corpus data. Both builds use identical hooks. All results are fresh; no publication certificate verdict is imported.

The retained runtime includes complete raw 7,376-row baseline, intermediate and final candidate registers, checkpoints, profiles, builds and logs. Compact compared rows and final structural results are committed with the local certificate. Ports are allocated by the operating system; each suite records its loopback origin. Profiles/downloads are unique to this runtime. All owned servers and browser contexts close on completion.
