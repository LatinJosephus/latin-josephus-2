# Browser test adjustments

Two test-harness mistakes were corrected without any production change. The initial Greek-presence assertion selected a literal nonexistent `tei-` element rather than elements with the TEI prefix; its failed diagnostic is retained. The first completed run used a baseline registry route glob without its cache-busting query suffix, so its before screenshots were not valid baseline comparisons. The route now includes the query suffix and explicitly requires the English unavailable message before each of six baseline captures. The complete forty-display suite was rerun after that correction; final BEFORE screenshots and BROWSER_QA.json come from the corrected run. The pre-fix functional results are retained as a diagnostic, not counted as final certification.
